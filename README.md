# UrbanSens Natura · geschützte Demo

Dieses Repository enthält ausschließlich **verschlüsselte** Artefakte der Web-Anwendung
(AES-256-GCM; Schlüssel aus E-Mail und Passwort per PBKDF2-SHA256 mit 300 000 Runden abgeleitet).
Ohne beide Angaben ist keine Datei lesbar. Quellcode, Rohdaten und Ergebnisse liegen nicht hier.

Zugang: die veröffentlichte Seite aufrufen, E-Mail und Passwort eingeben; die Anwendung wird im
Browser entschlüsselt und läuft dort vollständig lokal.
